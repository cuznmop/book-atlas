    书目信息

    怎么用

    1. 建书目：右上「书目信息」填书名、作者、出版社、ISBN、总页数。可以建多本，用左上角的「书目」下拉切换。
    2. 边读边记：左栏「当前页码」跟着你读到哪儿走；下面输入框敲人名回车，人和出场页一起进库。首次出现页留空就按当前页算。
    3. 别名：同一个人再敲一次别的名字（小名、字、号、绰号、原文名），会自动并成同一个人的别名，并记一次出场。战争与和平这种一堆译名的书特别好用。
    4. 关系：左栏「快速连关系」选两个人、写关系词、选类别。带起止页的关系会随时间轴出现或消失（例：吕布—董卓是义父子，董卓死后即止）。
    5. 经历与结局：右栏给每个人写分期经历（第几页到第几页做了什么）和最终结局。
    6. 聚类：中栏切换聚类方式，同府邸 / 同城 / 同国 / 同阵营的人会自动抱团，不同地区分开摆放。选「时期阵营」再拖时间轴，可以看三国这种阵营随页码变动的关系网。
    7. 存盘：数据自动存在浏览器本地（localStorage），换电脑用「导出 JSON / 导入 JSON」搬运。

    小技巧：滚轮缩放，拖背景平移，拖人物可以手动钉住位置；点人物看档案，双击人物聚焦它的邻域。
