# 书中人 · Book Atlas

> 读书时随手记人物、关系、地点与结局，最后长成一张**可聚类、可分期**的关系拓扑图。

纯静态前端：**零依赖 · 零构建 · 离线可用**。HTML + CSS + 原生 JS，聚类布局与力导向引擎全部自己写，不引任何 CDN 或第三方库——把文件夹拷到 U 盘里双击也能跑。

**🔗 在线试玩：<https://cuznmop.github.io/book-atlas/>**（打开就能玩，不用安装任何东西）

### 它能做什么

- **边读边记**：当前页码跟着书走，敲个人名回车就入库；同名再敲一次自动变成别名，并记一次出场。
- **重名不打架**：候选有多个时（《百年孤独》七代人都叫奥雷里亚诺）弹出带身份和出场页的编号表，按序号挑人。
- **关系带时间**：父子 / 主仆 / 结义 / 政敌…9 个类别各有颜色，还能带起止页，于是关系会随时间轴出现和消失。
- **多维度聚类**：地点 / 城市 / 国家 / 阵营 / 时期阵营 / 势力大类 / 世代标签 / 身份 / 自由力导，共 11 种。
- **分期经历与结局**：同一个人在不同时期可以有完全不同的经历，最终结局单独记。
- **书目齐全**：书名、作者、出版社、ISBN、版次、出版年、总页数一应俱全，支持多本书切换。
- **能带走**：数据存本地 localStorage，可导出 / 导入 JSON；图可导出 SVG / PNG。

## 快速开始

```powershell
cd bookchar
python -m http.server 8765 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8765/
```

Windows 上双击 `start.cmd` 也可以（会自动起服务并打开浏览器）。

> 直接双击 `index.html`（file://）也能用，但浏览器通常会禁止 file:// 页面写本地存储，数据刷新即丢。
> 推荐用上面的 http 方式，数据会自动存在浏览器 localStorage 里，另外随时可以「导出 JSON」备份。

第一次打开会弹出**书目信息**：书名、作者、出版社、ISBN、版次、出版年、总页数、备注。可以建多本，用左上角「书目」下拉切换。

## 边读边记的工作流

1. **跟着书走**：左栏「当前页码」跟着你读到哪儿填。它同时是时间轴，改它图上就会跟着变（未出场的人变灰，过期的关系隐藏）。
2. **见到人名就敲进去**：左栏输入框敲人名 → 回车。首次出现页留空就按当前页算。
   - 同一个人再敲一次别名（小名 / 字 / 号 / 绰号 / 译名），会自动并成同一个人的别名，并记一次出场。
   - 名字疑似同一个人（如「宝玉」vs「贾宝玉」）且开着「疑似同名时询问合并」时，会问你要不要合并——正是《战争与和平》一堆译名的场景。
   - 候选只有一个时问「是 / 否」；候选有多个时（《百年孤独》七代人都叫奥雷里亚诺、何塞·阿尔卡蒂奥、阿玛兰妲）会列出一条带身份和首次出场页的编号表，输入序号挑人，输入 0 就是另建一个新人。**读《百年孤独》时这个功能要么按序号仔细选，要么直接关掉开关**，否则很容易把两代人并成一个人。
3. **连关系**：左栏「快速连关系」选两个人 + 关系词 + 类别。关系可以带起止页，于是它会在时间轴上出现和消失（例：吕布—董卓是义父子，董卓一死关系即止）。
4. **补档案**：点图中任意一个名字，右栏展开 TA 的全部信息并可直接编辑——
   主名、身份、性别、首次出现页、结局页、出场页列表、别名列表、所在位置（地点 / 城市 / 国家 + 起止页）、阵营（阵营 / 集团 + 起止页）、自定义标签、分期经历、最终结局、备注。
5. **存盘**：自动写入 localStorage；「导出 JSON」把整个书架（含所有书）导出，「导入 JSON」或直接把文件拖进窗口即可还原。

快捷键：`/` 跳到人名输入框，`Esc` 关弹窗。

## 拓扑图怎么读

- **节点 = 人物**：圆越大，出场次数越多、关系越多。名字下面可以显示别名（勾「别名」）。写着结局的人外面有一圈金色虚线（勾「结局标记」）。
- **连线 = 关系**：按类别着色 —— 亲属 / 婚姻 / 主仆 / 师友 / 上下级 / 同盟 / 敌对 / 情感 / 其他，线上的字就是关系词（父子、主仆、结义…）。
- **灰掉 = 还没出场**：按当前页码过滤，人物首次出场页晚于当前页就变灰；关系不在生效期内就不画。
- **轮廓 = 聚类**：同一组的人被圈在一起，圈上有组名和人数。

操作：滚轮缩放，拖背景平移，拖人物钉住它，单击看档案，双击聚焦它的邻域，点图例里的分组可以直接飞到那一组。

## 聚类方式

| 方式 | 依据 | 适用 |
|---|---|---|
| 地点 · 归并 | 当前页所在地点，按 `·` 归并到主名 | 红楼梦 → 荣国府 / 大观园 / 宁国府… |
| 地点 · 细分 | 当前页所在地点全名 | 大观园·怡红院 / 大观园·潇湘馆… |
| 城市 | 当前页所在城市 | 战争与和平 → 莫斯科 / 彼得堡 / 童山… |
| 国家 / 地区 | 当前页所在国家 | 战争与和平 → 俄罗斯 / 法国 / 奥地利… |
| 阵营 · 随页码 | 当前页生效的阵营，该页没有记录就沿用最近一条 | 三国 → 蜀汉 / 曹魏 / 东吴；哈利·波特 → 凤凰社 / 食死徒 |
| 阵营 · 严格时期 | 严格只认当前页生效的阵营，其余归入「此页无阵营（未登场 / 已退场）」 | 拖时间轴看吕布从群雄到覆灭、姜维从曹魏到蜀汉 |
| 势力大类 | 阵营的 `group`（家族 / 学院 / 山寨 / 官方…） | 红楼梦 → 家族 / 丫鬟仆役 / 僧道；哈利·波特 → 学院 / 阵营 / 官方 |
| 首次出场阶段 | 首次出现页落在全书的哪一段 | 看谁先登场、谁后半程才出现 |
| 自定义标签 | 人物身上的自由标签 | 「主角」「贾府丫鬟」「第四卷才登场」 |
| 身份 / 阶层 | 身份字段 | 主仆、官阶、兵种 |
| 不聚类 | 自由力导向 | 纯看关系网形状 |

地点/城市/国家是**随页码变化的**：人物写了「3–1180 页在荣国府、1181 页起因出家在青埂峰」这样多条记录，时间轴一动，他就会换组。

## 导出

- **导出 SVG / PNG**：当前视图（含聚类轮廓与标签）导出成图片，可放进笔记或文章。
- **导出 JSON**：整个书架的结构化数据，随时可以再导入，或者自己用脚本处理。
- 浏览器本地存储不可用时（file:// 场景），页面会给出提示，此时请用 JSON 导出保存。

数据结构（导出的 JSON 就是这个形状）：

```jsonc
{
  "books": [{
    "meta": { "title": "红楼梦", "author": "曹雪芹", "publisher": "人民文学出版社",
              "isbn": "978-7-02-000220-7", "edition": "…", "year": "1996",
              "totalPages": 1606, "currentPage": 60, "note": "" },
    "characters": [{
      "primaryName": "贾宝玉",
      "names": [{ "text": "宝玉", "type": "小名" }],       // 全名 / 小名 / 字 / 号 / 绰号 / 译名…
      "role": "荣国府二公子", "gender": "男",
      "firstPage": 33, "appearances": [33, 66, 114],
      "locations":  [{ "place": "大观园·怡红院", "city": "京城", "country": "中国",
                       "fromPage": 358, "toPage": 1509 }],
      "factions":   [{ "name": "贾府", "group": "家族", "fromPage": 33, "toPage": null }],
      "groups": ["主角"],                                   // 自定义聚类标签
      "experiences":[{ "title": "衔玉而生", "fromPage": 1, "toPage": 30, "description": "…" }],
      "ending": "出家为僧", "endingPage": 1590, "note": ""
    }],
    "relations": [{
      "from": "c-1", "to": "c-2", "type": "表兄妹/知己", "category": "亲属",
      "sincePage": 200, "untilPage": null, "directed": true, "note": ""
    }]
  }]
}
```

`category` 取值固定为：`亲属 婚姻 主仆 师友 上下级 同盟 敌对 情感 其他`（决定连线颜色）。
`fromPage / toPage / sincePage / untilPage` 为 `null` 表示无界（从开头 / 一直持续）。

## 示例数据说明

`data/` 下的十部示例书目是**人物关系的描述性元数据**（谁和谁是什么关系、第几页出场、去了哪里、结局如何），由本项目整理，用于演示和测试。原著、人物、书名、ISBN 与出版社信息的权利归各自作者与出版方所有，本项目与它们没有关联。如果你要公开发布自己整理的书目数据，请自行确认合规。

示例数据中的页码对应的是**某一个阅读版本的页码**（写在各书 `meta.note` 里），换一个版本页号会对不上，这也是这个工具让你自己按手头的书录页码的原因。

## 贡献

欢迎 PR：新增书目数据、修 bug、改进聚类算法或界面都行。

- 只想加一本书：照 `data/book-*.js` 的格式写好，在 `index.html` 里加一行 `<script src="data/book-xxx.js"></script>` 即可。
- 改代码：没有构建步骤，直接编辑 `js/` 下的文件，刷新页面就能看到效果。
- 数据自检的口径：`id` 唯一、关系两端都存在、`appearances` 升序且首项等于 `firstPage`、所有区间 `fromPage ≤ toPage`、页码不超出 `totalPages`、`ending` 非空、关系起始页不早于两端人物的首次出场页。
